ACADEMIC PLANNER - how to put it on GitHub Pages

1. Open your site repository on GitHub (tijanaradenkovic.github.io).
2. Add file -> Upload files. Drag the whole "planer" folder (unzipped) onto the page.
   The files must end up in a folder called planer: index.html, manifest.webmanifest,
   sw.js, icon-192.png, icon-512.png.
3. Commit changes. After about a minute the planner is at:
   https://tijanaradenkovic.github.io/planer/
4. Open it in Chrome or Edge and click the install icon in the address bar to install it as an app.

Moving your data from the claude.ai version:
   old version -> Data -> Export JSON; new version -> Data -> Import JSON.

Updating later: replace index.html in the planer folder (GitHub -> planer/index.html -> pencil/upload).
The app picks up the new version the next time it is opened with an internet connection.
