Your data is saved only in this browser, on this device. Nobody else can see it, but clearing the browser data deletes it, and it does not appear on other devices. Export a backup file regularly: it is also how you move your data to another computer or phone (use Import JSON there).

Install as an app: in Chrome or Edge click the install icon in the address bar (or menu → Install). On iPhone use Share → Add to Home Screen.
